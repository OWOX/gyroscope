# Setup tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Checkup and Metrics with one Setup tab whose settings are stored as chosen, from which code derives the canvas model, with code and AI recommendations for every row.

**Architecture:** A version-5 settings document in the `settings` collection is the only source. `deriveModel` (pure) turns it plus the Data Mart schemas into today's `Model` shape, so the canvas, cards and queries keep working. `buildRows` (pure) turns settings, schemas and recommendations into Setup rows. Code recommenders run on every open; AI recommenders pick by index among code candidates and are cached in a new `suggestions` collection.

**Tech Stack:** TypeScript 5.9, React 19, Vite 8, Vitest 4 with happy-dom and Testing Library, `ai` 7 with zod 4, `@owox/plugin-sdk` 0.42.

**Spec:** `docs/superpowers/specs/2026-11-14-setup-tab-design.md`

## Global Constraints

1. Run tests only as `npx vitest run --maxWorkers=4 <path>` or `npm test` (already capped at 4 workers). Never run Vitest without the cap.
2. Saved settings are never computed by the AI. The AI only returns an index into a candidate list that code built.
3. Every row has exactly one option with `recommended: true`, in every state, with or without an AI credential.
4. Only rows `goal.metric` and `goal.date`, and data checks `check.goal.access` and `check.goal.pk`, have severity `error`.
5. Only admins write `settings` and `suggestions`. A member never starts an AI call.
6. The AI uses the credential's `fast` tier (`handle.fast ?? handle.reasoning`).
7. Copy: titles in Title Case as in the spec tables (they are product names), questions and why sentences in sentence case, no em dashes, no Markdown in AI answers.
8. Release 0.5.0, delivered from `https://owox.github.io/gyroscope/v5/`. `plugin.json` keeps `model`, `ontology` and `ontology_project`, and adds `{ "name": "suggestions", "scope": "project" }`.
9. Commit messages follow the repo style (`feat:`, `fix:`, `test:`, `docs:`, `chore:`, `release:`) and end with `Co-Authored-By: Claude Opus 5.5 (1M context) <noreply@anthropic.com>`.
10. Match the surrounding code: dense one-line helpers, a one-line `/** */` comment above exported functions, no comment on obvious lines.

## Review Focus

1. **A 0.4 settings doc with `industry` and `coreClasses`** must read as empty v5 settings with its `thresholdPct` kept, and the old core ids must come back as the core recommendation. Test in Task 1 and Task 5.
2. **A saved field that was renamed or deleted in OWOX** must show as a broken row with a repick recommendation, never crash `deriveModel` or drop the whole canvas. Test in Task 3 and Task 6.
3. **Two admins saving at once** must give a `SettingsConflict` to the second, and the UI must reload instead of overwriting. Test in Task 1 and Task 10.
4. **A ratio whose denominator is 0 or missing on some days** must give `null` for those values, not `Infinity` or `NaN`. Test in Task 2.
5. **A project with no Data Marts at all, or none with a numeric field,** must still give every row a recommended option (a "Not available yet" option that opens the Data Marts page). Test in Task 6.

```ts
import type { CollectionsLike } from './collections';
import type { Measure, MetricChoice, MetricFormat, MetricKind, PlanDef, PlanShape, ProjectSettingsV5, RatioSetting } from '../types';

export const EMPTY_SETUP: ProjectSettingsV5 = {
  v: 5, goal: null, coreClasses: [], contexts: {}, classes: {}, plans: {}, formats: {}, ratios: [],
  thresholdPct: 20, dismissed: [], updatedAt: null, updatedBy: null,
};

type Raw = Record<string, unknown>;
const obj = (v: unknown): Raw | null => (v && typeof v === 'object' && !Array.isArray(v) ? (v as Raw) : null);
const str = (v: unknown): v is string => typeof v === 'string' && v.length > 0;
const FNS = ['SUM', 'COUNT', 'COUNT_DISTINCT', 'AVG', 'MIN', 'MAX'];
const FORMATS: MetricFormat[] = ['number', 'percent', 'currency'];
const SHAPES: PlanShape[] = ['daily', 'cumulative', 'level'];
const measureOf = (v: unknown): Measure | null => {
  const m = obj(v);
  return m && str(m.field) && (m.fn === null || FNS.includes(m.fn as string)) ? { field: m.field, fn: m.fn as Measure['fn'] } : null;
};
const choiceOf = (v: unknown): MetricChoice | null => {
  const c = obj(v); const measure = measureOf(c?.measure);
  if (!c || !str(c.martId) || !measure || !(c.kind === 'flow' || c.kind === 'level')) return null;
  return { martId: c.martId, measure, dateField: str(c.dateField) ? c.dateField : null, kind: c.kind as MetricKind, alias: str(c.alias) ? c.alias : measure.field };
};
const planOf = (v: unknown): PlanDef | null => {
  const p = obj(v); const measure = measureOf(p?.measure);
  return p && str(p.martId) && measure && str(p.dateField) && SHAPES.includes(p.shape as PlanShape) ? { martId: p.martId, measure, dateField: p.dateField, shape: p.shape as PlanShape } : null;
};
const record = <T,>(v: unknown, each: (x: unknown) => T | null): Record<string, T> =>
  Object.fromEntries(Object.entries(obj(v) ?? {}).flatMap(([k, x]) => { const r = each(x); return r === null ? [] : [[k, r]]; }));
const strings = (v: unknown): string[] => (Array.isArray(v) ? v.filter(str) : []);
const threshold = (v: unknown) => (typeof v === 'number' && Number.isFinite(v) ? Math.min(100, Math.max(1, v)) : EMPTY_SETUP.thresholdPct);

/** A stored doc as v5 settings; a doc from before v5 keeps only its threshold. */
export function readSetup(raw: unknown): ProjectSettingsV5 {
  const r = obj(raw) ?? {};
  if (r.v !== 5) return { ...EMPTY_SETUP, thresholdPct: threshold(r.thresholdPct) };
  const goalChoice = choiceOf(r.goal);
  const ratioOf = (v: unknown): RatioSetting | null => {
    const x = obj(v);
    return x && str(x.id) && str(x.name) && str(x.numerator) && str(x.denominator) ? { id: x.id, name: x.name, numerator: x.numerator, denominator: x.denominator, format: FORMATS.includes(x.format as MetricFormat) ? (x.format as MetricFormat) : 'number' } : null;
  };
  return {
    v: 5,
    goal: goalChoice ? { ...goalChoice, plan: planOf(obj(r.goal)!.plan) } : null,
    coreClasses: strings(r.coreClasses).slice(0, 7),
    contexts: record(r.contexts, (x) => { const c = obj(x); return c ? { metric: choiceOf(c.metric), plan: planOf(c.plan) } : null; }),
    classes: record(r.classes, (x) => { const c = obj(x); return c ? { keyMetricId: str(c.keyMetricId) ? c.keyMetricId : null, shown: (Array.isArray(c.shown) ? c.shown : []).map(choiceOf).filter((m): m is MetricChoice => !!m) } : null; }),
    plans: record(r.plans, planOf),
    formats: record(r.formats, (x) => { const f = obj(x); return f && FORMATS.includes(f.format as MetricFormat) ? { format: f.format as MetricFormat, currency: str(f.currency) ? f.currency : null } : null; }),
    ratios: (Array.isArray(r.ratios) ? r.ratios : []).map(ratioOf).filter((x): x is RatioSetting => !!x),
    thresholdPct: threshold(r.thresholdPct),
    dismissed: strings(r.dismissed),
    updatedAt: str(r.updatedAt) ? r.updatedAt : null,
    updatedBy: str(r.updatedBy) ? r.updatedBy : null,
  };
}

/** The core Data Mart ids a 0.4 doc chose; they come back as recommendations, never as settings. */
export const legacyCore = (raw: unknown): string[] =>
  (Array.isArray(obj(raw)?.coreClasses) ? (obj(raw)!.coreClasses as unknown[]) : []).flatMap((e) => (str(obj(e)?.martId) ? [obj(e)!.martId as string] : []));

const readRaw = async (ctx: CollectionsLike): Promise<Raw> => obj((await ctx.collections<unknown>('settings').get('project'))?.document) ?? {};

export async function loadSetup(ctx: CollectionsLike): Promise<{ settings: ProjectSettingsV5; legacyCore: string[] }> {
  const raw = await readRaw(ctx);
  return { settings: readSetup(raw), legacyCore: raw.v === 5 ? [] : legacyCore(raw) };
}

export class SettingsConflict extends Error {
  constructor(public by: string | null, public at: string | null) {
    super('Setup changed since it was loaded');
    this.name = 'SettingsConflict';
  }
}

/** Writes `next` only when the stored doc still has `base`'s updatedAt; keys the settings don't own stay. */
export async function saveSetup(ctx: CollectionsLike, base: ProjectSettingsV5, next: ProjectSettingsV5, by: string, now: Date): Promise<ProjectSettingsV5> {
  const raw = await readRaw(ctx);
  const stored = readSetup(raw);
  if (stored.updatedAt !== base.updatedAt) throw new SettingsConflict(stored.updatedBy, stored.updatedAt);
  const saved: ProjectSettingsV5 = { ...next, v: 5, updatedAt: now.toISOString(), updatedBy: by };
  const { industry: _i, coreClasses: _c, ...kept } = raw;
  await ctx.collections<unknown>('settings').put('project', { ...kept, ...saved });
  return saved;
}

export interface SuggestionsDoc { inputHash: string; at: string; items: Record<string, string> }

export async function loadSuggestions(ctx: CollectionsLike): Promise<SuggestionsDoc | null> {
  const d = obj((await ctx.collections<unknown>('suggestions').get('current'))?.document);
  return d && str(d.inputHash) && str(d.at) ? { inputHash: d.inputHash, at: d.at, items: record(d.items, (x) => (str(x) ? x : null)) } : null;
}

/** Adds one AI pick; a doc for another hash is replaced. */
export async function saveSuggestion(ctx: CollectionsLike, inputHash: string, rowId: string, optionId: string, now: Date): Promise<void> {
  const cur = await loadSuggestions(ctx);
  const items = cur && cur.inputHash === inputHash ? cur.items : {};
  await ctx.collections<SuggestionsDoc>('suggestions').put('current', { inputHash, at: now.toISOString(), items: { ...items, [rowId]: optionId } });
}
```

```ts
import type { MetricDef, MetricResult, RangeSpec, SeriesPack } from '../types';
import { addDays } from '../lib/dates';
import { diffPct, statusOf } from '../lib/stats';
import type { OwoxLike } from '../owox/sources';
import { computeMetric, type ComputeOut } from './compute';

/** n ÷ d, or null when either is missing or d is 0. */
export const divide = (n: number | null, d: number | null): number | null => (n === null || d === null || d === 0 ? null : n / d);

const daysBetween = (a: string, b: string) => Math.round((Date.parse(`${b}T00:00:00Z`) - Date.parse(`${a}T00:00:00Z`)) / 86_400_000);

/** The ratio's result from its two sides; the series is laid on the numerator's days. */
export function combineRatio(num: ComputeOut, den: ComputeOut, thresholdPct: number): ComputeOut {
  const n = num.result, d = den.result;
  const error = n.error ?? d.error;
  const base: MetricResult = {
    fact: null, compareFact: null, comparison: null, diffPct: null, plan: null, forecast: null, forecastApprox: false,
    status: 'neutral', trend: 'flat', note: null, error: null,
  };
  if (error) return { result: { ...base, error }, spark: null };
  const fact = divide(n.fact, d.fact);
  const comparison = divide(n.comparison, d.comparison);
  let spark: SeriesPack | null = null;
  if (num.spark && den.spark) {
    const shift = daysBetween(den.spark.start, num.spark.start);
    spark = { start: num.spark.start, values: num.spark.values.map((v, i) => divide(v, den.spark!.values[i + shift] ?? null)), forecastStart: null, forecast: [] };
  }
  const trend = n.trend === d.trend ? 'flat' : n.trend === 'up' || d.trend === 'down' ? 'up' : 'down';
  return { result: { ...base, fact, comparison, diffPct: diffPct(fact, comparison), status: statusOf(fact, null, thresholdPct), trend }, spark };
}

/** Computes both sides of a ratio metric with no plan or forecast, then divides. */
export async function computeRatio(args: { owox: OwoxLike; metric: MetricDef; byId: ReadonlyMap<string, MetricDef>; spec: RangeSpec; thresholdPct: number }): Promise<ComputeOut> {
  const { owox, metric, byId, spec, thresholdPct } = args;
  const side = (id: string) => {
    const m = byId.get(id);
    if (!m) return Promise.resolve<ComputeOut>({ result: { fact: null, compareFact: null, comparison: null, diffPct: null, plan: null, forecast: null, forecastApprox: false, status: 'neutral', trend: 'flat', note: null, error: `Metric ${id} is not in the model` }, spark: null });
    return computeMetric({ owox, metric: { ...m, plan: null, forecast: null }, spec, thresholdPct, withSpark: true });
  };
  const [num, den] = await Promise.all([side(metric.ratio!.numerator), side(metric.ratio!.denominator)]);
  return combineRatio(num, den, thresholdPct);
}
```

```ts
import { fetchBlendable, fetchInputs, fetchMartDetail, type Inputs, type OwoxLike } from '../owox/sources';
import { describeError } from '../lib/errors';
import { runPool } from '../lib/pool';
import type { MartNode } from './graph';

export interface Graph { inputs: Inputs; nodes: MartNode[]; failed: Map<string, string> }

/** Every listed Data Mart's schema and sources, 6 at a time; one that fails is in `failed`, never thrown. */
export async function loadGraph(owox: OwoxLike, onProgress?: (done: number, total: number) => void): Promise<Graph> {
  const inputs = await fetchInputs(owox);
  let done = 0;
  const total = inputs.marts.length;
  onProgress?.(0, total);
  const got = await runPool(inputs.marts.map((m) => async (): Promise<MartNode> => {
    try {
      const [detail, blendable] = await Promise.all([fetchMartDetail(owox, m.id), fetchBlendable(owox, m.id)]);
      return { id: m.id, title: m.title, contexts: m.contexts, detail, blendable };
    } finally { onProgress?.(++done, total); }
  }), 6);
  const failed = new Map<string, string>();
  got.forEach((r, i) => { if (r.status === 'rejected') failed.set(inputs.marts[i]!.id, describeError(r.reason)); });
  return { inputs, nodes: got.flatMap((r) => (r.status === 'fulfilled' ? [r.value] : [])), failed };
}
```

```ts
/** The canvas model the settings describe, over the schemas as they are now. Never calls the AI; equal inputs give an equal model. */
export function deriveModel(s: ProjectSettingsV5, g: Graph): Derived {
  if (!s.goal) return blocked('NO_GOAL', 'The Business Critical Number is not set.');
  if (!s.goal.dateField) return blocked('GOAL_NO_DATE', 'The Critical Number Date is not set.');
  const goal = s.goal;
  const byId = new Map(g.nodes.map((n) => [n.id, n]));
  const goalNode = byId.get(goal.martId);
  if (!goalNode) return blocked('GOAL_NO_ACCESS', "You can't access the Data Mart that owns the critical number.");
  const has = (d: MartDetail, path: string | null) => path === null || allFieldPaths(d.fields).has(path);
  if (!has(goalNode.detail, goal.measure.field)) return blocked('GOAL_FIELD_NOT_FOUND', `${goal.measure.field} isn't in ${goalNode.title} any more.`);
  if (!has(goalNode.detail, goal.dateField)) return blocked('GOAL_NO_DATE', `${goal.dateField} isn't in ${goalNode.title} any more.`);
  if (!hasPrimaryKey(goalNode.detail)) return blocked('GOAL_NO_PRIMARY_KEY', `${goalNode.title} has no primary key.`);

  const visible = new Set(g.inputs.marts.map((m) => m.id));
  const edges = buildEdges(g.nodes, visible);
  const classable = new Set(g.nodes.filter((n) => hasPrimaryKey(n.detail)).map((n) => n.id));
  const depths = classDepths(goal.martId, edges, classable);
  const core = new Set(s.coreClasses.filter((id) => classable.has(id)));
  const touchesGoal = (id: string) => edges.some((e) => (e.from === goal.martId && e.to === id) || (e.from === id && e.to === goal.martId));
  for (const id of core) if (!depths.has(id) && touchesGoal(id)) depths.set(id, 1);

  const fmt = (id: string) => s.formats[id] ?? { format: 'number' as const, currency: null };
  const usable = (c: MetricChoice) => { const n = byId.get(c.martId); return !!n && has(n.detail, c.measure.field) && has(n.detail, c.dateField); };
  const def = (c: MetricChoice, role: MetricDef['role'], source: string, plan: MetricDef['plan']): MetricDef => {
    const id = metricId(c.martId, c.measure);
    const field = flattenFields(byId.get(c.martId)!.detail.fields).find((x) => x.path === c.measure.field)?.field;
    return { id, martId: c.martId, alias: c.alias, measure: c.measure, kind: c.kind, dateField: c.dateField, role, source, isUniqueCount: false, plan, shown: true, ...fmt(id), forecast: null, calculated: !!field?.calculated, description: field?.description ?? null };
  };

  const add = (m: MetricDef) => { if (!metrics.has(m.id)) metrics.set(m.id, m); };
  const goalDef = def(goal, 'critical', 'project', goal.plan);
  add(goalDef);
  for (const [ctxId, c] of Object.entries(s.contexts)) if (c.metric && usable(c.metric) && depths.has(c.metric.martId)) add(def(c.metric, 'critical', ctxId, c.plan));

  for (const n of g.nodes) {
    const depth = depths.get(n.id);
    if (depth === undefined) continue;
    const own: string[] = [];
    if (n.id === goal.martId) own.push(goalDef.id);
    for (const m of metrics.values()) if (m.martId === n.id && !own.includes(m.id)) own.push(m.id);
    const uc = uniqueCountMetric(n.detail, n.blendable);
    if (uc) { add({ ...uc, ...fmt(uc.id) }); if (!own.includes(uc.id)) own.push(uc.id); }
    for (const c of s.classes[n.id]?.shown ?? []) {
      if (!usable(c)) continue;
      const m = def(c, 'leading', 'project', s.plans[metricId(c.martId, c.measure)] ?? null);
      add(m);
      if (!own.includes(m.id)) own.push(m.id);
    }
    for (const r of s.ratios) {
      if (metrics.get(r.numerator)?.martId !== n.id && !(s.classes[n.id]?.shown ?? []).some((c) => metricId(c.martId, c.measure) === r.numerator) && !(n.id === goal.martId && r.numerator === goalDef.id)) continue;
      const num = metrics.get(r.numerator);
      if (!num) continue;
      add({ ...num, id: r.id, alias: r.name, role: 'leading', source: 'project', isUniqueCount: false, plan: null, forecast: null, format: r.format, currency: r.format === 'currency' ? num.currency : null, calculated: false, description: null, ratio: { numerator: r.numerator, denominator: r.denominator } });
      own.push(r.id);
    }
    const chosen = s.classes[n.id]?.keyMetricId;
    const key = chosen && own.includes(chosen) ? chosen : n.id === goal.martId ? goalDef.id : uc && own.includes(uc.id) ? uc.id : own[0] ?? null;
    const ordered = key ? [key, ...own.filter((id) => id !== key)] : own;
    classes.push({ id: n.id, martId: n.id, title: n.title, contexts: n.contexts, depth, keyMetricId: key, metricIds: ordered, shown: true, core: core.has(n.id), inbound: 0 });
  }
  // a ratio's denominator must be computable even when its class isn't drawn
  for (const r of s.ratios) if (!metrics.has(r.denominator)) metrics.delete(r.id);
  const inbound = inboundCounts(edges);
  for (const c of classes) c.inbound = inbound.get(c.id) ?? 0;
  classes.sort((a, b) => a.depth - b.depth || a.title.localeCompare(b.title) || a.id.localeCompare(b.id));
  const kept = new Set(classes.flatMap((c) => c.metricIds));
  for (const r of s.ratios) if (kept.has(r.id)) kept.add(r.denominator);
  const { updatedAt, updatedBy, ...content } = s;
  return {
    ok: true,
    model: {
      version: 3,

      builtAt: updatedAt ?? 'never',

      editedAt: null, editedBy: null,
      goal: { classId: goal.martId, metricId: goalDef.id, goalMartId: goal.martId, viaFallback: false },

      metrics: [...metrics.values()].filter((m) => kept.has(m.id)).sort((a, b) => a.id.localeCompare(b.id)),
    },
  };
}
```

```ts
export function coreCandidates(goalId: string, nodes: MartNode[], edges: Edge[], legacy: string[]): string[] {
  const ranked = rankCore({ goalId, nodes: nodes.map((n) => ({ id: n.id, title: n.title, singleKey: singleKey(n.detail) })), edges });
  return [...legacy.filter((id) => ranked.includes(id)), ...ranked.filter((id) => !legacy.includes(id))];
}

/** As many as are referenced by two or more Data Marts, kept within 3 to 7. */
export function coreDefault(cands: string[], edges: Edge[]): string[] {
  const inbound = inboundCounts(edges);
  const strong = cands.filter((id) => (inbound.get(id) ?? 0) >= 2).length;
  return cands.slice(0, Math.min(7, Math.max(3, strong)));
}

export function keyFor(classId: string, model: Model): string | null {
  const c = model.classes.find((x) => x.id === classId);
  const ms = (c?.metricIds ?? []).map((id) => model.metrics.find((m) => m.id === id)!).filter(Boolean);
  return (ms.find((m) => m.plan) ?? ms.find((m) => m.isUniqueCount) ?? ms.find((m) => m.measure.fn === 'SUM') ?? ms[0])?.id ?? null;
}

/** Up to 3 numbers for the card besides the key: calculated fields first, then numeric fields. */
export function shownFor(classId: string, model: Model, node: MartNode): FieldCand[] {
  const keyField = model.metrics.find((m) => m.id === model.classes.find((c) => c.id === classId)?.keyMetricId)?.measure.field;
  const all = numericFields([node]).filter((f) => f.path !== keyField);
  const calc = new Set(node.detail.fields.filter((f) => f.calculated).map((f) => f.name));
  return [...all.filter((f) => calc.has(f.path)), ...all.filter((f) => !calc.has(f.path))].slice(0, 3);
}

export interface RatioPair { numerator: string; denominator: string; name: string }

export function ratioPairs(model: Model, nodes: MartNode[]): RatioPair[] {
  const cls = new Map(model.classes.map((c) => [c.id, c]));
  const byId = new Map(model.metrics.map((m) => [m.id, m]));
  const node = new Map(nodes.map((n) => [n.id, n]));
  const references = (fromId: string, toId: string, field: string) =>
    (node.get(fromId)?.detail.fields ?? []).some((f) => f.calculated && parseRefs(f.calculated.formula).some((r) => r.path === toId && r.field === field));
  const out: RatioPair[] = [];
  for (const e of model.edges) {
    const a = cls.get(e.from), b = cls.get(e.to);
    const num = a?.keyMetricId ? byId.get(a.keyMetricId) : undefined;
    const den = b?.keyMetricId ? byId.get(b.keyMetricId) : undefined;
    if (!num || !den) continue;
    if (references(e.from, e.to, den.measure.field) || references(e.to, e.from, num.measure.field)) continue;
    out.push({ numerator: num.id, denominator: den.id, name: `${num.alias} per ${den.alias}` });
  }
  return out;
}
```

```ts
const singular = (s: string) => s.toLowerCase().replace(/ies$/, 'y').replace(/s$/, '');

export function pickPrimaryKey(node: MartNode): string | null {
  const flat = flattenFields(node.detail.fields).filter(({ field }) => /^id$|_id$|Id$/.test(field.name));
  const score = ({ field }: (typeof flat)[number]) => (field.name.toLowerCase() === `${singular(node.id)}_id` || field.name === 'id' ? 0 : 2) + (field.mode === 'NULLABLE' ? 1 : 0);
  return flat.map((x, i) => ({ x, i })).sort((a, b) => score(a.x) - score(b.x) || a.i - b.i)[0]?.x.path ?? null;
}

const tokens = (s: string) => new Set(s.toLowerCase().split(/[^a-z0-9]+/).filter(Boolean));
function distance(a: string, b: string): number {
  const d = Array.from({ length: b.length + 1 }, (_, i) => i);
  for (let i = 1; i <= a.length; i++) {
    let prev = d[0]!; d[0] = i;
    for (let j = 1; j <= b.length; j++) { const t = d[j]!; d[j] = Math.min(d[j]! + 1, d[j - 1]! + 1, prev + (a[i - 1] === b[j - 1] ? 0 : 1)); prev = t; }
  }
  return d[b.length]!;
}

/** The field closest to a gone path: most shared name tokens, then fewest edits. */
export function repick(path: string, node: MartNode, keep: (f: FieldCand) => boolean): FieldCand | null {
  const want = tokens(path);
  const cands = flattenFields(node.detail.fields).map(({ path: p, field }): FieldCand => ({ martId: node.id, martTitle: node.title, path: p, label: field.alias || field.name, type: field.type.toUpperCase() })).filter(keep);
  const shared = (c: FieldCand) => [...tokens(c.path)].filter((t) => want.has(t)).length;
  return cands.sort((a, b) => shared(b) - shared(a) || distance(path, a.path) - distance(path, b.path))[0] ?? null;
}
```

```ts
export const AI_ROWS = /^(goal\.metric|goal\.plan|core\.classes|teams\.exist|team:[^.]+\.(metric|plan)|metric:.+\.plan|ratio:.+)$/;
const MAX_OPTIONS = 30;
const Pick = z.object({ pick: z.number().int() });

/** Changes when what a recommendation reads changes: descriptions, and each Data Mart's title and fields. */
export const factsHash = (g: Graph): string => hashString(JSON.stringify([
  g.inputs.projectDescription,
  [...g.inputs.contexts].sort((a, b) => a.id.localeCompare(b.id)).map((c) => [c.id, c.description]),
  [...g.nodes].sort((a, b) => a.id.localeCompare(b.id)).map((n) => [n.id, n.title, flattenFields(n.detail.fields).map((x) => `${x.path}:${x.field.type}`).sort()]),
]));

/** The AI's choice among the row's options, by index; null when it can't answer. Never throws. */
export async function aiPick(row: Row, facts: { projectDescription: string | null; contextName?: string }, generate: GenerateWith): Promise<string | null> {
  const opts = row.options.slice(0, MAX_OPTIONS);
  if (opts.length === 1) return opts[0]!.id;
  const prompt = [
    `A business user is asked: "${row.question}" (${row.title}${facts.contextName ? `, for ${facts.contextName}` : ''}).`,
    'Pick the best answer from the OPTIONS by its index. Use only the facts below.',
    `PROJECT DESCRIPTION:\n${facts.projectDescription?.trim() || '(empty)'}`,
    `OPTIONS:\n${opts.map((o, i) => `${i}: ${o.label}`).join('\n')}`,
  ].join('\n\n');
  try {
    const r = Pick.safeParse(await generate(prompt, Pick));
    return r.success && r.data.pick >= 0 && r.data.pick < opts.length ? opts[r.data.pick]!.id : null;
  } catch { return null; }
}
```

`useSetup` behaviour:

1. `reload()`: `loadSetup(store)` and `loadGraph(owox)` in parallel, then `loadSuggestions(store)`. Derives with `deriveModel` and calls `onModel(derived, graph)`. Builds rows.
2. After a reload, when `isAdmin && generateWith` and the stored suggestions' `inputHash !== factsHash(graph)` (or no doc), it runs `aiPick` for every row whose id matches `AI_ROWS` and whose state isn't `done`, at most 4 at a time with `runPool`, marking each id in `aiPending` while it runs. Each answer is saved with `saveSuggestion` and merged into `ai`, and the rows are rebuilt. A member never runs this.
3. `onChoose(rowId, optionId)`: finds the option, sets `busyRow`, runs `runAction`. On `{ ok: true }` it stores the new settings, re-derives, calls `onModel`, rebuilds rows. On a conflict it sets `message` to `"{by} changed setup at {HH:MM}. Reloaded."` and calls `reload()`. On an error it sets `message` to the error, plus the snippet when given.
4. `onDismiss(rowId)`: runs a `set` action adding `rowId` to `dismissed`.
5. An `append` or `teams` action is followed by `reload()`, since it changes the descriptions or contexts.

`App.tsx` changes:

1. `depsFrom`: AI handle becomes `handle?.fast ?? handle?.reasoning`; drop `generate`, keep `generateWith`.
2. Replace the body of `load` with: fetch the member, call `setup.reload()`. In `onModel(d, graph)`: when `d.ok`, `setModel(d.model)`, `setInputs({ model: d.model, data: graph.inputs })`, and show `ready` (or the start tab); when blocked, show `{ name: 'blocked', blocked: d.blocked }`. A member and an admin follow the same path; there is no `not_set_up` view any more, a blocked member sees the blocked screen with "Ask a project admin to finish Setup".
